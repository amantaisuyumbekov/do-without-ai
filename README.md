# DO WITHOUT AI

> Learn by building. Think independently. Code by yourself.

## About the Project

**Do Without AI** is an ongoing experiment and learning project focused on software development without relying on Artificial Intelligence to write code or solve programming problems.

The main idea is simple: instead of asking AI for solutions, I want to understand problems, research documentation, make mistakes, debug code, and develop my own solutions.

This repository will continuously grow as I learn new concepts, explore technologies, and build new projects.

## 🎯 Main Goals

- Develop independent problem-solving skills.
- Improve programming and algorithmic thinking.
- Understand how things work instead of just copying solutions.
- Learn to read official documentation.
- Practice debugging and finding errors independently.
- Build projects from scratch.
- Track personal progress over time.

## 🧠 Development Philosophy

The project follows a few simple principles:

1. **Think first** — Try to understand the problem before searching for solutions.
2. **Research** — Use official documentation, books, and reliable learning resources.
3. **Build independently** — Write the implementation yourself.
4. **Make mistakes** — Errors are part of the learning process.
5. **Understand everything** — Avoid using code that you cannot explain.
6. **Keep improving** — Revisit old projects and improve them.
